Source: PharmUtilities/Dosettijakelu (private)

This repository is generated distribution state, never a source or data archive.
Actions remain disabled until isolated, signed publication is implemented.

Public payloads require exact-hash acceptance, product/architecture/version
validation, package and per-file hashes, independently signed release and index
metadata, production data exclusion and third-party redistribution notices.

The draft early manifest schema is not a production trust protocol. No unsigned
index, placeholder trust root, expired metadata fallback or AptUtil endpoint may
be used to bootstrap production trust.
